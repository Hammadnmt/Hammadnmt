## 🔧 What I've Built

**Cloud-Native Kubernetes Microservices Mesh** — Declarative multi-tier microservices architecture running on Kubernetes ([Repository](https://github.com/Hammadnmt/kubernetes-microservices-deployment)). Built with Go and minimal multi-stage Docker containers (~15MB), featuring automated service discovery via CoreDNS, zero-downtime rolling updates, horizontal self-healing replicas, and inter-service health orchestration.

**E-Commerce & ERP Order Automation** — Order-to-cash automation connecting Shopify/WooCommerce to SAP Business One and Odoo. Signed webhook intake (HMAC-verified), automatic ERP sales orders/invoices/payments, warehouse allocation, courier integration, and a barcode-verified packing dashboard. Built as 5 NestJS microservices on PostgreSQL.

**AI Cost Estimator & Lead Capture System** — Instant cost-estimation platform for an engineering firm: a 9-question dynamic flow, emailed reports, lead capture, and a dashboard for non-technical pricing updates. Custom CMS with role-based admin permissions. Next.js + Tailwind, NestJS + Mongoose + MongoDB, OpenAI API.

**Investor Relations Website** — Investor-facing site for the Saudi Uzbek Business Council ([su-bc.com](https://su-bc.com)). Strapi CMS backend with custom content collections, Next.js frontend, Lenis smooth-scroll interactions, dark/light theming. Delivered in 2 weeks, live in production.
