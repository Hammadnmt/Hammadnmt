# Hi, I'm Hammad 👋

Full-stack developer, 2+ years of experience, working mainly with **Next.js, NestJS, PostgreSQL, and MongoDB**. I build full-stack systems that replace manual business processes — ERP integrations, order workflows, and admin tooling.

## 🔧 What I've Built

**E-Commerce & ERP Order Automation** — Order-to-cash automation connecting Shopify/WooCommerce to SAP Business One and Odoo. Signed webhook intake (HMAC-verified), automatic ERP sales orders/invoices/payments, warehouse allocation, courier integration, and a barcode-verified packing dashboard. Built as 5 NestJS microservices on PostgreSQL.

**AI Cost Estimator & Lead Capture System** — Instant cost-estimation platform for an engineering firm: a 9-question flow, emailed reports, lead capture, and a dashboard for non-technical pricing updates. Custom CMS with role-based admin permissions. Next.js + Tailwind, NestJS + Mongoose + MongoDB, OpenAI API.

**Investor Relations Website** — Investor-facing site for the Saudi Uzbek Business Council ([su-bc.com](https://su-bc.com)). Strapi CMS backend with custom content collections, Next.js frontend, Lenis smooth-scroll interactions, dark/light theming. Delivered in 2 weeks, live in production.
